# WioCinema

TMDB/IMDb kimlikli katalogla yabancı film ve dizi sağlayıcılarını tek eklentide toplar. Kaynak grubu başlangıçta yabancı sağlayıcılara ayarlıdır.

## CloudStream Kurulumu

CloudStream deposuna şu adresi ekleyin:

```text
https://raw.githubusercontent.com/Wiojelt/WioCinema/main/repo.json
```

## Nuvio Kurulumu

Nuvio Desktop / Android uygulamasında **Settings → Plugins / Eklentiler** alanına şu manifest adresini ekleyin:

```text
https://raw.githubusercontent.com/Wiojelt/Nuvio-Addons/main/wiocinema/manifest.json
```

Doğrudan bu depodan eklemek isterseniz:

```text
https://raw.githubusercontent.com/Wiojelt/WioCinema/main/manifest.json
```
